# xrMPE United Pack

Addon for **X-Ray Multiplayer Extension**

## Описание

**United Pack** — это аддон для **X-Ray Multiplayer Extension**, предназначенный для объединения нескольких сторонних аддонов в единый, согласованный пакет с дополнительными правками и улучшениями. Официальные ресурс платформы: https://www.xrmpe.online/

## Цели

- реализовать возможность игры с некоторыми аддонами на одном сервере
- убрать необходимость устанавливать и поддерживать каждый аддон по отдельности
- устранить ошибки и недочеты
- добавить новые функции и контент

---

## Основные возможности

- Объединение нескольких аддонов в один
- Исправление ошибок
- Дополнительные изменения и улучшения поверх исходных аддонов
- Упрощённая установка и обновление
- Ориентация на режим **Оборона**

## Назначение

United Pack предназначен для:

- администраторов мультиплеер-серверов
- разработчиков модификаций под **X-Ray Multiplayer Extension**
- игроков

## Структура репозитория

```text
gamedata/
 ├─ config/
 │   ├─ *.ltx *.xml      # Конфигурационные файлы
 ├─ levels/
 │   └─ level_name/       # Игровой уровень
 │        └─ ...
 ├─ meshes/
 │   ├─ *.ogf            # Геометрические модели
 │   └─ *.omf            # Анимации
 ├─ scripts/
 │   └─ *.lua            # Скриптовые файлы
 ├─ sounds/
 │   └─ *.ogg            # Звуковые файлы
 ├─ textures/
 │   ├─ *dds            # Файлы текстур
 │   └─ *thm            # Файлы настроек текстур
 └─ ...
 ```

## Принципы

- открытый исходный код, в т.ч. артефакты
- конфиги включаемых аддонов хранятся в отдельных файлах, которые включаются в общий файл. В имени файла должно присутствовать имя аддона-источника.

## Статус

Проект находится в активной разработке.
Состав объединяемых аддонов и набор правок может расширяться
