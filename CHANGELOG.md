# CHANGELOG

## [0.3.0] - 2026-07-06

### Levels

- Добавлен уровень **Лиманск** (`df_limansk`)
  - Основан на уровне Лиманск из аддона **[Seven pack 1.6](https://ap-pro.ru/forums/topic/4177-seven-pack-16/)**
  - Добавлены тайники
  - Уменьшено количество лута в ящиках
  - Добавлены зажигаемые костры
  - Добавлена ночная логика
  - Добавлены аномалии
  - Добавлено помещение электробудки
  - Динамическая погода

- Добавлен уровень **Арена** (`df_arena`)
  - Основан на уровне Арена из аддона **[Seven pack 1.6](https://ap-pro.ru/forums/topic/4177-seven-pack-16/)**
  - Изменена фракция игроков на Сталкеров
  - Фракция противников выбирается случайно каждый раунд
  - Оптимизирована логика рестрикторов
  - Изменен ассортимент торговца

- **Центр Припяти** (`df_pripyat_center`)
  - Изменение баланса лута

### Gameplay

- Флаер
- Осветительные артефакты **Лунный свет** и **Пламя**
- Спички для розжига временных костров
- Динамическая погода на всех уровнях
- Случайное время суток на старте на всех уровнях
- Ночной лут на всех уровнях
- Возврат сильного тумана
- Английская локализация

### AI

- Настроено зрение НПС под погоду
- НПС с репутацией -1000 всегда держат оружие в руках и враги игрокам
- Контроллер теперь враг монолитовцам

### Configs

- Добавлена система подключаемых рестрикторов для дополнительной логики
- Рандом времени суток можно задать для каждого уровня
- Добавлены нпс для обороны: Бандиты, Наемники, Монолит, Зомбированные
- Электра теперь не светится

### Спавнер (The Tool)

- Добавлены новые предметы и НПС

### Fixed

- Рестрикторы проверяют теперь наличие только живых игроков
- Альтернативные подствольные гранаты больше не могут использоваться
- Исправлен спавн боеприпасов скриптами
- Исправлены вылеты менеджера тайников на оригинальных картах

## [0.2.0] - 2026-03-04

### Levels

- Добавлен уровень **Кафе Припять** (`df_pripyat`)
  - Основан на одноимененном уровне Кафе Припять из аддона **[Seven pack 1.6](https://ap-pro.ru/forums/topic/4177-seven-pack-16/)**
  - Добавлены тайники
  - Уменьшено количество лута в ящиках
  - Добавленые объекты за пределами игровой зоны

### Gameplay

- Механика управляемых костров на новых уровнях (постоянные и временные)
- Увеличена бронезащита шлемов
- Погода и шанс выпадания предметов теперь не повторяются при частых рестартах сервера
- Увеличение частоты солнечной погоды в ущерб дождливой и туманной
- Энергетик в слоте быстрого доступа правильно подхватывается из инвентаря
- Энергетик дает большую прибавку и дольше действует
- Уменьшена скорость пули для Грозы и Вала
- Изменения лута и спавна предметов на уровне **Центр Припяти**

### AI

- Уменьшено влияние освещения на зрение НПС

### Scripts

- Интеграция части скриптов из аддона **Seven pack 1.6**
- Улучшения стабильности при ошибках в конфигах предметов, выпадающих из разбиваемых ящиков
- Переработка модуля `treasure_manager`, предметы больше не копируются и не остаются в оффлайне, вместо этого лишние удаляются с уровня.
- Правильная инициализация рандомайзера при старте игры
- В `m_netpk` доработана передача флага отладки во вложенные классы
- Добавлен сканер `clsid` в лог в реалтайме

### Configs

- Интеграция множества конфигов из аддона **Seven pack 1.6**
  - оружие
  - предметы
  - костюмы
  - настройки выпада предметов
  - настройки мутантов, которых нет на классике
  - звуки окружения
  - и т.д.
- Откат изменений классов мультиплеерных предметов

### Спавнер (The Tool)

- Добавлены интегрированные из аддона **Seven pack 1.6** предметы
- Больше не требует наличия строк в fsgame.ltx

### Graphics

- Интегрированы некоторые текстуры из аддона **Seven pack 1.6**

### Fixed

- Вылеты при старте игры на классических картах
- Позиционирование предметов тайников
- Текстуры неба пасмурной погоды

## [0.1.0] - 2026-02-05

### Levels

- Добавлен уровень **Центр Припяти** (`df_pripyat_center`)
  - Основан на уровне Припять из мода **[Живая зона](https://ap-pro.ru/forums/topic/4023-zhivaya-zona-obt/)**
  - Заточен под волны мутанов + NPC с оружием

### Gameplay

- Отдача СВД, СВУ увеличена
- Время исчезновения трупов NPC увеличено
- Время исчезновения трупов игроков увеличено
- Урон от падения увеличен
- Смех - новый пункт в меню сообщений игроков

### AI

- NPC больше не светят фонариками ночью
- NPC больше не поднимают оружие с земли
- Зрение NPC:
  - дальность стандарт ~80м
  - дальность снайперов ~120м
  - ускоренная реакция
- Сопротивляемость урону у NPC немного перенастроена

### Scripts

- Интеграция модулей `lua_extension`, `lua_helper`, `xml_utils` и `m_netpk` из **The Tool**
- Интеграция спавнера [The Tool](https://www.amk-team.ru/forum/topic/14989-instrument/)
- Создание модуля **Remote Command** для удаленного вызова методов на сервере с клиента с контролем авторизации (**скриптовый админ**)
- Поддержка нормального чтения конфигов в обход движкового класса `ini_file`
- Переработка модуля `treasure_manager`, чанковый контроль спавна тайников, расширение настроек наполнения уровня тайниками

### Configs

- Профили NPC-противников и спаун-секции вида `<фракция>_<ранг>`
  - Сталкеры-нейтралы: `neutral_normal`, `neutral_veteran`, `neutral_master`
  - Свобода: `freedom_normal`, `freedom_veteran`, `freedom_master`
  - Долг: `duty_normal`, `duty_veteran`, `duty_master`
  - Военные: `military_normal`, `military_veteran`, `military_master`
- Профили и спаун-секции NPC-снайперов: `freedom_sniper`, `duty_sniper`, `military_sniper`

### The Tool

- Регулировка текущего времени суток через ползунок (как перед сном)
- Отключение автосмены погоды отдельным флагом
- Настройка списков предметов и погоды под **xrMPE UP**

### Graphics

- Погода из [DMR Pack](https://ap-pro.ru/forums/topic/4567-dmr-pack-053-dlya-xrmpe/)
- Погодные варианты из мода [CGIM 2](https://ap-pro.ru/forums/topic/3409-cgim-2/)
- Подсветка аномалий Холодец включена
- Радиус свечения костров увеличен
- Погода "Темный туман" - увеличен радиус тумана до 80-100м

### Fixed

- Вылеты связанные со звуками от NPC, с файлом `sound_theme.script`
